---
title: 术语表
description: 产品和 API 中使用的术语。
---

| 术语 | 含义 |
| --- | --- |
| 租户 | 一个客户空间：拥有自己的成员、内容、已连接账号和设置 |
| 租户编码 | 标识租户的短编码，登录时使用 |
| 成员 | 租户内的用户 |
| 模板 | 平台的可复用内容形态；可提供默认目标 |
| 技能 | 从技能市场安装的可复用写作增强 |
| 技能安装 | 租户拥有的技能副本，具有固定版本和使用授权 |
| 自动化任务 | 按计划生成并发布内容的定时指令 |
| 运行 | 任务计划的一次执行：生成、草稿、发布 |
| 草稿 | 等待审核或发布的内容 |
| 审核 | 审批环节：批准、要求修改或驳回草稿 |
| 发布 | 平台上已发布的内容，带有跟踪的指标和评论 |
| 素材 | 租户拥有的图片：上传的、生成的或用作封面的 |
| 图片模式 | 任务获取图片的方式：`generate`（生成）或 `library`（素材库） |
| MCP | Model Context Protocol——外部工具的插件系统 |
| 访问令牌 / 刷新令牌 | 登录签发的 Bearer 凭证；刷新令牌每次使用后轮换 |
