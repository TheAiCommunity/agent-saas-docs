## 什么是租户编码？

登录时用于标识你租户的短编码。它不是你在 API 中看到的租户 ID——编码只用于登录。

## 为什么首次登录后必须修改密码？

由管理员创建的账号以临时密码开始。首次登录需要设置你自己的密码后才能使用产品。这只会发生一次。

## 为什么我的内容卡在审核里？

默认每篇内容都需要审核。命中敏感词、缺少必须声明、包含不允许的外链域名或超出长度限制的内容也会被标记审核。微信群发始终需要人工批准。

## 一个任务最多能用几个技能？

最多十个。技能按列出顺序生效，每个都必须已在你租户中安装并授权使用。

## 为什么抖音不能用生成的图片？

抖音任务的图片来自你的素材库。素材库模式同样适用平台的各种图片限制。

## 为什么我的集成会遇到 CORS 错误？

内容 API 不提供跨域请求支持。浏览器应用应通过同源代理或同域网关调用。

## 完整的 API 文档在哪里？

见[内容 API 参考](../developer/api-reference.md)，由 OpenAPI 规范生成，在线 Swagger 界面在 [saas.theaicommunity.net/swagger/content](https://saas.theaicommunity.net/swagger/content/index.html)。
