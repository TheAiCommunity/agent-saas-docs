先在“插件”找到需要的平台，阅读接入指南并免费开通，再完成该平台的账号连接。安装插件不会替你登录，也不会自动取得发布权限。

## 内容平台准备表

| 平台 | 由谁准备 | 连接前提 |
| --- | --- | --- |
| B站 | 开发者 + 账号持有人 | 开发者配置应用；账号持有人 OAuth 授权 |
| X / Twitter | 开发者 + 账号持有人 | X 开发者应用、合适的 API 方案及账号 OAuth 授权 |
| 公众号 | 公众号管理员 | 公众号 AppID、配套 AppSecret、接口权限与服务器 IP 白名单 |
| 小红书 | 账号持有人 | 本人扫码登录；用户无需填写 MCP Key |
| 抖音 | 开发者 + 账号持有人 | 应用 Client Key / Secret、回调和所需权限 |
| 朋友圈 | 账号持有人 | GeWe 服务 Token、微信节点 AppID，以及本人扫码 |
| 视频号 | 账号持有人 | 已授权微信节点与已开通的视频号能力；开通朋友圈不代表能发布视频号 |

## 连接并检查账号

1. 打开对应插件详情，先阅读“接入与使用指南”。
2. 点击“免费开通并启用”，再点击“连接 / 管理平台账号”。
3. 按平台页面完成配置、本人扫码或 OAuth 授权；密钥只在产品指定的配置入口填写。
4. 回到插件选择刚连接的账号，点击“重新检查账号/能力”。
5. 展开“可用操作与授权状态”，分别确认草稿、分享或服务端发布。

## 常见平台差别

- **公众号**：先核对 AppID、AppSecret、接口权限和服务端出口白名单。能交付草稿不代表具备正式发布权限。
- **小红书**：由本人扫码并完成安全验证；服务端运行环境由运维准备，用户无需提供 MCP Key。会话失效时按产品入口重新登录。
- **B站**：账号信息权限与投稿权限分别核实；仅有 USER_INFO 不能推导可投稿，视频投稿还需 ARC_BASE。
- **抖音**：按页面实际能力选择内容准备、平台分享或获准的投稿路径。本人在抖音完成确认后，还要核对最终作品结果。
- **朋友圈和视频号**：使用有效微信节点；微信号和手机号不能替代节点 AppID。视频号为实验能力，不能从朋友圈就绪推导视频号可发布。
- **X**：开发者方案、接口权限和账号 OAuth 需要同时满足。

## 企业应用：一次公司配置，员工各自连接

飞书、钉钉、Gmail、WPS、Notion、GitHub、Google Drive 和 Google Calendar 由公司管理员先完成应用配置，员工再按需连接自己的账号或确认允许读取的应用范围。

当前查询边界包括：飞书机器人可见群、钉钉授权部门、GitHub 公开项目、Notion 共享页面、WPS 目录与元数据、Drive 文本资料、Calendar 事件。Gmail 有读信和确认后保存草稿的实现，没有发送工具。完整清单见[插件目录](mcp.md)。

本批企业连接器尚无真实厂商联通验收；Google 接入已延期。GitHub 公司应用准备完成也不等于已配置进产品或员工已授权。
