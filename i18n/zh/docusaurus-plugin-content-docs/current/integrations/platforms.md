---
title: 社媒平台连接
description: 每个受支持平台如何连接到鲸芽 Agent。
---

鲸芽 Agent 通过你一次性连接的账号进行发布。由于各平台规则不同，连接方式也不同。

| 平台 | 连接方式 | 说明 |
| --- | --- | --- |
| 小红书 | 引导式 Cookie 登录 | 为每个账号创建登录会话；会话可刷新或重置 |
| 微信公众号 | 账号配置 | 使用前通过连接检查；支持正式发布与群发 |
| 抖音 | OAuth 授权 | 在抖音开放平台授权；另有 H5 分享方式 |
| B站 | OAuth 授权 | 使用 B站 官方发布流程 |
| X | OAuth 授权 | 标准 OAuth 流程 |
| 个人微信 | 托管连接 | 连接一个个人微信工作区，拥有独立的会话管理 |

## OAuth 平台

连接抖音、B站、X 账号时，会打开平台的授权页面。你在那里批准授权，平台回调鲸芽 Agent 完成连接。回调地址已在各平台登记，因此授权只能通过产品界面完成——无法手工拼 URL。

## 小红书 Cookie 登录

小红书没有公开的发布 API，因此平台为每个已连接的账号维护一个浏览器登录会话。登录流程会一步步引导你；之后会话保持在线并自动刷新。如果会话失效——例如在小红书改了密码——从连接页面重新登录该账号。如果平台开始拒绝请求，还可以重置账号的浏览器身份。

## 微信公众号

添加公众号的配置，然后运行连接检查。微信任务区分两种投递方式：

- **正式发布** — 内容走微信的发布流程。
- **群发** — 内容发给关注者；该模式始终需要人工审核。

## 平台允许什么

每个平台都会暴露自己的能力——可以做哪些内容类型和操作。应用按平台读取它们（API 中的 `GET /v1/platforms/{platform}/capabilities`），所以界面上看到的已经是平台实际允许的范围。
