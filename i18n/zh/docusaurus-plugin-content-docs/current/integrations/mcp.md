插件为工作台提供办公文件、网页资料、内容平台和企业应用工具。当前目录包含内置业务工具和企业连接器；不要把它理解为任意插件包或 CLI 都可直接导入运行。

## 免费安装并启用

1. 在左侧点击“插件”，搜索所需能力。
2. 进入详情，查看用途、前提和接入指南。
3. 点击“免费开通并启用”。如仍显示“公司未配置”或“待授权”，继续完成准备步骤。
4. 返回工作台，在“应用与插件”选择本轮使用的工具。

## 公司管理员与员工分别做什么

公司管理员在“公司集成”保存开发者应用或搜索服务配置；员工通过连接入口登录自己的厂商账号，确认所需范围。飞书、钉钉等应用型连接还受公司应用权限和可见范围限制。


![公司管理员填写应用配置的空表单](/img/tutorials/20261023/06-company-config-fields.png)

*2026-10-23 本地空表单：只展示字段，不含任何真实密钥。*


配置保存后仍要检查连接和具体操作权限。需要创建文件、保存草稿或对外写入时，核对产品的执行确认信息；不要把连接成功当作写入成功。

## 网页阅读和联网搜索

- 有明确公开网页链接时，阅读不需要搜索 Key，但仍受网页访问条件及当前网络限制。
- 需要主动检索时，公司管理员配置 Tavily 或 Brave Search Key，二选一即可。
- 结果中的来源链接用于核对资料；网页提取或搜索结果都不能自动当作已核实事实。
