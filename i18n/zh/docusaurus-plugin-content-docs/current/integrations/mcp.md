description: 安装 MCP 插件并控制工具访问。

鲸芽 Agent 可以通过 MCP（Model Context Protocol）插件扩展。一个 MCP 插件是一个暴露工具的服务器——平台可以调用的外部系统，例如搜索、数据源或内部服务。插件通过插件市场分发，按租户安装。

## 插件访问机制

- 平台侧维护插件目录：有哪些插件、版本，以及每个版本暴露的工具。
- 租户安装插件后逐个工具授权访问。访问默认拒绝——未被明确授权的工具不可调用。
- 插件凭证加密存储，设置完成后不再以明文返回。
- 每次工具调用都会记录日志；日志条目经过脱敏，并保留有限时间。

## 版本

插件版本一旦发布即冻结：其端点、传输方式和工具定义不可更改。如果插件在后续版本中新增了工具，安装新版本后所有新工具默认拒绝，直到被明确授权。

## 在哪里管理

安装和工具授权由租户管理员在管理后台操作；目录本身由平台侧维护。同样的规则适用于作为技能运行时的 MCP 服务器。
