素材库保存内容任务可复用的图片和视频；办公文档插件保存当前员工生成的文件。这两类材料分别使用对应入口管理。

## 上传内容素材

1. 在任务配图或素材选择入口打开 **内容素材库**。
2. 点击“上传素材”，选择文件。
3. 填写名称、代号、说明、标签、分组及适用平台，确认上传。
4. 回到任务选择素材，核对图片或视频与目标内容类型匹配。

当前前端接受 **20 MiB 以内的 JPEG、PNG、GIF、WebP 或 MP4**。平台交付还有独立要求；上传成功不等于目标平台接受这种格式。

## 查找、修改与恢复

- 可按名称或代号查找，也可选择全部信息搜索，再按分组、平台和类型筛选。
- 编辑素材只更新资料信息，原文件及已有任务引用保留。
- 删除素材会移入回收站；它不再出现在新任务选图中，已有引用仍可读取。需要再次使用时，在回收站恢复。
- 删除分组后，素材转为未分组，文件保留。

## 自动配图与视觉方法

任务中的“生成图片”依赖已配置的生图服务、可用额度和后台执行条件。不能用 Skill 的存在推导生图服务已经可用。

“信息图创意工坊”“知识漫画编剧”“视频提示导演”当前输出结构、分镜和提示。要交付真实媒体文件，还需要相应的制作或生成环节。使用现有 MP4 的视频任务，也不等于平台会替你生成视频。

## 生成并下载 Word

1. 在插件中免费安装“办公文档”，回到工作台选择它。
2. 提供或确认正文，说明需要 Word、Excel、PPT、CSV、Markdown 等哪种格式。
3. 检查文件生成确认卡，核对动作和内容后确认执行。
4. 在生成的文件卡片点击“下载文件”，打开文件核对正文。
