title: 审核与发布
description: 分别确认内容、交付路径和最终平台结果。

内容草稿、审核通过、保存到平台草稿箱和正式发布，是不同的结果。每一步都应查看对应状态。

## 审核一篇草稿

1. 打开任务详情的“内容预览”。
2. 检查标题、正文、图片或视频、来源和待确认信息。
3. 阅读审核原因；需要修改时按页面提供的操作处理。
4. 批准前核对目标账号和交付方式。若确认卡将执行发布，确认其范围后再继续。

## 正确理解状态

| 页面结果 | 能说明什么 |
| --- | --- |
| 已生成草稿 | 内容已准备，仍需检查 |
| 已批准 | 当前版本通过内容审核，交付还需满足权限和平台条件 |
| 已保存平台草稿 | 平台草稿箱已有内容，不能写成正式发布成功 |
| 已准备分享或投稿二维码 | 还需按平台流程由本人完成确认；二维码状态不代表作品已发布 |
| 结果待确认 | 远端结果尚未核实，先查询结果，避免直接重复提交 |
| 发布成功 | 以平台确认结果及可核对的回执或作品为依据 |

公众号如采用草稿交付，审核后保存至微信草稿箱，再由账号管理员到微信后台手动发表。工作台不会把手动发表自动当成已核实的发布成功。

## 发布前再检查账号能力

打开对应插件，点击“重新检查账号/能力”，查看“可用操作与授权状态”。账号已连接，只表示身份连接完成；草稿准备、分享路径与服务端发布仍分别判断。

## 失败或结果未知时

查看任务的“运行记录”和“发布状态”，先处理明确的账号、权限或素材问题。结果未知时优先核实平台作品和回执；确认未成功且页面允许后再重试。对外报告应使用页面实际结果，如“草稿已保存”或“等待平台确认”。
