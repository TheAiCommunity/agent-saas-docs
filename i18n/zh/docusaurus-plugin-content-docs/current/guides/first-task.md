---
title: 创建第一个任务
description: 先完成草稿，再按需要建立持续内容任务。
---

工作台支持一次对话中的内容处理，也支持持续运行的内容任务。先用真实材料得到一版可审阅草稿，再配置计划和平台交付，会更容易核对结果。

## 先完成一次对话任务

1. 打开工作台的“连续对话”。
2. 选择已安装的 Skill；需要工具时，打开“应用与插件”选择本轮范围。
3. 写清材料、受众、目标、交付形式，以及哪些信息还不确定。
4. 发送后检查输出；需要文件时使用办公文档插件。


![工作台选择本轮应用与插件](/img/tutorials/20261023/14-workbench-plugin-picker.png)

*2026-10-23 本地工作台菜单：待配置的服务仍会提示准备事项。*


## 建立持续内容任务

在“多平台任务”或“任务列表”进入内容任务创建界面，按当前账号可用的入口填写：

| 设置 | 怎么填 |
| --- | --- |
| 任务名称 | 使用自己能辨认的名称，如“每周产品知识草稿” |
| 目标平台与账号 | 选择自己有权使用的账号，先检查平台与账号能力 |
| 主题与目标 | 写清内容范围、读者和希望产出的形式 |
| 内容模板 | 按需选择；核对模板带入的默认目标 |
| Skills | 仅选已安装且有权使用的方法；内容自动化任务最多 10 项 |
| 素材与配图 | 使用已有素材，或在服务支持时配置生图；视频使用可用视频素材 |
| 生成调度与时区 | 选择间隔或每天固定时间，并核对时区 |
| 目标总数 | 按界面显示的发布、内容或草稿交付口径填写 |
| 审核方式 | 首次使用建议保留“发布前人工审核” |

工作台一轮最多选 **3 项 Skills**；内容自动化任务表单最多选 **10 项**。这是两个不同的入口。

## 保存前核对

先看页面的缺项提示和账号能力提示。若页面显示“只准备本地草稿”“草稿交付”或“能力待开通”，按该范围使用；不要把任务创建成功当作已投稿或已发表。


![任务调度与人工审核设置](/img/tutorials/20261023/24-schedule-editor.png)

*2026-10-17 历史本地编辑界面：用于说明计划、时区和审核字段；图中的日期不是当前推荐排期。*


保存后到任务详情查看“运行记录”“内容预览”和交付状态。持续计划的说明见[自动化运行](automation.md)，发布前的判断见[审核与发布](review-and-publish.md)。
