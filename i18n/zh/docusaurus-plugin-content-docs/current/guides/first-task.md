---
title: 创建第一个任务
description: 自动化任务由什么组成，以及如何配置一个任务。
---

自动化任务是一条持续执行的指令：按计划就某个主题为某个平台生成内容，通过已连接的账号发布，直到达到总量目标。任务在后台运行——你不需要每次按按钮。

## 任务的组成部分

| 组成部分 | 作用 |
| --- | --- |
| 主题与目标 | 写什么、写给谁、写成什么形式 |
| 平台与账号 | 内容发布到哪里、以哪个账号发布 |
| 模板 | 平台的内容形态；设置了模板时可提供默认目标 |
| 技能 | 最多十个已安装的写作技能，影响输出风格 |
| 计划 | 按间隔生成，或每天固定时间生成一次 |
| 发布目标 | 任务总共应产出多少篇成功发布 |
| 图片 | 自动生成的图片，或从素材库中挑选的图片 |

## 必填设置

- `task_name` — 任意非空名称
- `platform` — `xiaohongshu`、`wechat` 或 `douyin`
- `account_id` — 该平台上已连接的账号
- `topic` — 写什么
- `goal` — 模板未提供默认目标时必填
- `schedule` — 间隔模式需要 `frequency_seconds`；每日模式需要 `schedule.time`（00:00–23:59）
- `total_publish_target` — 大于零的数字

微信任务还需要投递方式：正式发布或群发。群发始终需要人工审核。

## 各平台行为差异

- 小红书：标题默认限 20 字、正文限 1000 字；超长文本会在审核中标出。
- 微信公众号：每次运行最多生成 8 篇文章；封面默认使用第一张生成的图片，你也可以指定。
- 抖音：抖音任务的图片必须来自素材库，不能使用 URL。

## 接下来会发生什么

每次计划触发时，任务会生成一批草稿和图片。草稿进入审核（如果任务被允许自动发布，则直接发布）。错过的每日运行会被跳过，不会补跑。
