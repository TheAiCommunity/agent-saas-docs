title: 自动化运行与排期
description: 设置生成计划，核对下一次运行并查看结果。
---

内容任务按计划生成内容，后续再进入审核和交付。生成调度不等于平台已经授权自动发布。

## 选择生成计划

1. 打开任务创建或编辑界面。
2. 在“生成调度”选择 **按时间间隔** 或 **每天固定时间**。
3. 间隔模式填写秒数；每日模式填写开始生成时间。
4. 核对时区。例如团队按北京时间工作时使用 `Asia/Shanghai`。
5. 新任务如需指定第一轮时间，填写“首次运行时间”；留空时按调度尽快安排第一轮。
6. 首次使用保留人工审核，并根据需要勾选“仅生成一个主题批次”。

## 修改已有计划

下一次运行时间由后台计算，在界面只读显示。修改间隔或每日时间会重新计算后续排期；仅修改文案等其他字段时保留原排期。界面也提供“保存时按当前设置重新排期”用于修正旧排期。

已经暂停的任务，在保存后仍需按页面提示手动恢复。恢复前再次核对草稿、账号和交付范围。

## 查看每一轮结果

进入任务详情后，分别查看：

| 位置 | 检查内容 |
| --- | --- |
| 运行记录 | 本轮何时开始、结束，是否失败及失败原因 |
| 内容预览 | 正文、素材、审核结果 |
| 图片生成 | 生图状态、已有结果和错误提示 |
| 发布状态 / 草稿交付与发布记录 | 实际交付、待确认、失败或已核实成功 |

任务总目标按界面当前口径统计。草稿交付总数、已确认发布数和结果待确认数不能互相替代；总数目标也不保证平台一定接受所有内容。

## 排查没有按时运行

先检查任务是否暂停、下一次运行时间和时区是否符合预期，再看账号与模型服务是否就绪。若有失败，按记录修复后使用页面允许的重试操作；不要仅因没有新作品就重复创建同一任务。

真实发布和外发是否开启由服务配置及权限决定。当前资料包的本地截图不包含持续线上运行或真实发布验收，生产环境应由运维另行确认执行服务与排期。
