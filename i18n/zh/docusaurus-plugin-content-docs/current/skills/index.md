---
title: 技能
description: 安装写作技能，并在任务中使用它们。
---

技能是可复用的写作增强。一个技能携带指令——有时还有输入字段——影响内容模型的写作方式：语气、结构、钩子、合规规则等。

## 获取技能

技能来自技能市场，由平台侧维护。浏览和安装都在产品界面完成；你安装的技能会成为租户拥有的**技能安装**。

安装技能不会自动对所有人开放使用：管理员控制每个安装的可用者。如果某个技能没有出现在任务的技能列表里，联系你的租户管理员。

## 在任务中使用技能

- 一个任务最多引用十个技能安装，按列出顺序生效。
- 部分技能定义输入字段（由技能的 `input_schema` 决定）；挂载技能时按字段填写。
- 任务会锁定创建时使用的安装版本，因此技能更新不会悄悄改变运行中任务的行为。你可以显式将安装升级到新版本。

## 当前技能能做与不能做的事

技能目前只影响写作本身（`prompt` 和 `builtin` 类型）。内容任务中的技能暂不支持联网搜索、调用 HTTP 接口、执行脚本或调用 MCP 工具。
