## 租户

每个账号都属于一个租户：一个拥有自己的成员、内容、已连接账号和设置的客户空间。租户通过**租户编码**标识——登录时输入的短编码。租户编码与 API 响应中出现的租户 ID 不是同一个东西；编码用于登录，ID 在内部标识租户。

登录时使用用户名、邮箱或手机号，加密码。

## 首次登录

如果账号是由租户管理员创建的，首次登录会要求先设置新密码，然后才能使用产品。这是正常流程，只发生一次。

## 会话

登录会创建绑定到你设备的会话。会话在一段时间后过期；使用期间应用会自动刷新令牌。

你可以随时在应用中退出登录。租户管理员可以在管理后台查看并撤销成员会话——例如设备丢失时。

## 修改密码

在个人设置中修改密码。如果无法访问账号，联系你的租户管理员。
