鲸芽账号用于进入工作空间；微信、飞书、GitHub 等账号用于连接外部平台。它们分别登录和授权。

## 准备登录信息

向所在团队的鲸芽管理员取得 **租户编码、登录账号、初始密码**。租户编码用于选择工作空间；不要把内部租户 ID 当作租户编码填写。登录账号可使用团队分配的用户名或已登记的邮箱、手机号，具体以管理员开通的信息为准。

## 登录与首次改密

1. 打开[产品登录页](https://saas.theaicommunity.net/)。
2. 填写“租户编码”“账号”“密码”，点击“登录”。
3. 如出现“设置新密码”，填写当前密码和新密码，再保存。
4. 进入工作台后，确认自己看到的是预期团队的功能入口。

## 登录后看不到功能

功能入口同时受角色权限和服务配置影响。没有安装、公司配置或管理入口时，联系团队管理员确认权限。不要换用同事账号，也不要在教程或聊天中提交密码、Token 或应用密钥。

## 会话失效与密码问题

会话失效时重新登录。首次改密未完成时，先完成页面要求。忘记密码或不清楚租户编码时，由团队管理员核查；不要反复试猜其他空间的编码。

## 公司配置和个人连接

公司管理员在 **插件 → 公司集成** 完成开发者应用或搜索服务配置；员工之后只为自己的业务需要连接账号、确认访问范围。公司的配置保存成功，不表示所有员工已经授权。
