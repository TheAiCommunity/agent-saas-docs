第一次使用，先完成一个能直接核对结果的文字整理任务。这个示例不需要社媒账号，也不需要搜索服务。

## 1. 登录工作空间

打开[鲸芽 Agent](https://saas.theaicommunity.net/)，填写管理员提供的租户编码、账号和密码。若页面要求设置新密码，完成后再继续。遇到登录问题，查看[账号与登录](accounts.md)。

## 2. 安装“素材整理与引用”

在左侧打开 **Skills**，搜索“素材整理与引用”。进入详情查看方法、来源和版本，点击 **一键安装**。安装后返回工作台，在本轮对话选择这个 Skill。工作台一轮最多选择 3 项方法。

## 3. 发送一段真实材料

确认工作台处于“连续对话”。将下面示例中的信息换成自己的材料，再发送：

> 请使用“素材整理与引用”方法，把以下材料分成已知事实、待确认事项和两版简短文案。只依据我提供的信息，不补造日期、人数或效果。材料：我们准备组织一次社区学习交流；活动日期、地点和报名方式尚未确定。先给我草稿，不创建发布任务。


![发送前已选中素材整理与引用](/img/tutorials/20261023/15-skill-chat-before-send.png)

*2026-10-23 本地真实流程：发送前确认本轮方法标签。*


## 4. 检查结果

核对事实有没有被改写，缺失信息是否保留“待确认”，是否明确为草稿。需要修改时直接指出句段和目标，不必重新安装 Skill。


![文字模型返回两版草稿](/img/tutorials/20261023/16-skill-real-output.png)

*2026-10-23 真实文字模型输出：保留待确认信息；这一步没有发布内容。*


## 5. 需要文件时再导出

安装并选择 **办公文档** 插件，发送“把刚才的整理结果生成 Word，保留待确认事项”。检查文件生成确认卡，确认后下载文件。完整步骤见[素材、图片与文件](../guides/assets.md)。

完成标志是你已经拿到并核对一份草稿或文件。连接平台账号、开启连续任务可以随后进行，见[创建第一个任务](../guides/first-task.md)。
