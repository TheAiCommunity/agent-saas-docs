本页介绍从登录到发布第一篇内容的最短路径。产品团队将补充截图与最终文案；以下事实均对照当前产品核实。

## 准备工作

- 一个租户中的账号。登录需要租户编码，以及用户名、邮箱或手机号。
- 至少一个受支持平台的社交媒体账号：小红书、微信公众号、抖音、B站或X。
- 一个面向目标平台的模板。

## 1. 登录

打开鲸芽 Agent 应用，使用租户编码和账号信息登录。首次登录会要求先修改密码。详见[账号与登录](accounts.md)。

## 2. 连接社交媒体账号

各平台的连接方式不同——有的走 OAuth，小红书使用引导式 Cookie 登录。见[社媒平台连接](../integrations/platforms.md)，然后回来继续。

## 3. 选择模板与技能

模板决定内容的形态与目标。技能是可选的写作增强，从技能市场安装；每个任务最多使用十个。见[技能](../skills/index.md)。

## 4. 创建自动化任务

一个任务至少需要：

| 字段 | 说明 |
| --- | --- |
| `task_name` | 任务名称 |
| `platform` | 发布平台：`xiaohongshu`、`wechat` 或 `douyin` |
| `account_id` | 用于发布的已连接账号 |
| `topic` | 写什么 |
| `goal` | 受众、角度与形式（模板提供默认值时可省略） |
| `schedule` | 生成频率：按间隔，或每天固定时间 |
| `total_publish_target` | 总计应成功发布多少篇 |

分步说明见[创建第一个任务](../guides/first-task.md)。

## 5. 审核与发布

默认情况下，生成的内容等待你审核。你可以批准、要求修改或驳回每篇草稿；批准的内容发布到已连接的账号。任务也可以被允许自动发布。详见[审核与发布](../guides/review-and-publish.md)。

## 6. 观察运行

每个任务都会保留运行历史、报告与建议，见任务面板。见[自动化运行](../guides/automation.md)。
