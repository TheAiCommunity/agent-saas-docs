The asset library stores images and videos that content tasks can reuse; the office documents plugin stores files generated by the current employee. The two kinds of material are managed at their own entrances.

## Upload content assets

1. Open the **content asset library** from the task image picker or the asset entrance.
2. Click "Upload asset" and choose files.
3. Fill in name, code, description, tags, group and applicable platforms, then confirm the upload.
4. Back in the task, select the asset and check that the image or video matches the target content type.

The current frontend accepts **JPEG, PNG, GIF, WebP or MP4 up to 20 MiB**. Platform delivery has its own requirements; a successful upload does not mean the target platform accepts the format.

## Find, edit and restore

- Search by name or code, or search all fields and filter by group, platform and type.
- Editing an asset updates its information only; the original file and existing task references are kept.
- Deleting an asset moves it to the recycle bin; it no longer appears in new task pickers, existing references keep working. Restore it from the recycle bin to use it again.
- Deleting a group turns its assets ungrouped; files are kept.

## Auto images and visual methods

"Generate image" in a task depends on a configured image service, available quota and backend execution conditions. A skill existing does not imply the image service is ready.

"Infographic studio", "Knowledge comic screenwriter" and "Video prompt director" currently output structure, storyboards and prompts. Delivering real media files still needs the corresponding production or generation step. A video task using an existing MP4 also does not mean the platform generates videos for you.

## Generate and download a Word file

1. Install "Office documents" from plugins for free, then select it back in the workbench.
2. Provide or confirm the body text, and say which format you need: Word, Excel, PPT, CSV, Markdown, and so on.
3. Check the file generation confirmation card, verify the action and content, then confirm.
4. On the generated file card click "Download file", then open the file and check the text.
