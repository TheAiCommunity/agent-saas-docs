---
title: Assets and images
description: The asset library and the two ways tasks get images.
---

Assets are the images your tenant owns: uploaded files, generated images, and covers. They are organized in groups and can be reused across tasks.

## Where images come from

Tasks get images in one of two modes:

**Generate** — the platform produces images for each draft. You can control:

- how many images per draft (1–3)
- image size (2K or 4K)
- a style description
- up to six reference images from your library to steer the result

**Library** — the task uses existing images from your asset library. You pick the image set per task; nothing is generated. Douyin tasks require library mode; generated images are not used for Douyin.

WeChat official account posts need a cover: in library mode you either pass an authorization reference for the cover or the first library image is used; in generate mode the first generated image becomes the cover.

## Asset rules worth knowing

- Library images must be in a ready state and fit the target platform.
- WeChat official account content only accepts JPEG and PNG images.
- Image URLs from the internet are accepted for Xiaohongshu and WeChat library mode, but Douyin only accepts library asset IDs.
