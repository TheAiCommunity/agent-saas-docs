---
title: Glossary
description: Terms used throughout the product and the API.
---

| Term | Meaning |
| --- | --- |
| Tenant | A customer space with its own members, content, connected accounts, and settings |
| Tenant code | Short code identifying a tenant, used at sign-in |
| Member | A user inside a tenant |
| Template | A reusable content shape for a platform; can provide a default goal |
| Skill | A reusable writing add-on installed from the skill market |
| Skill installation | A tenant-owned copy of a skill, with a fixed version and usage grants |
| Automation task | A scheduled instruction to generate and publish content |
| Run | One execution of a task's schedule: generation, drafts, publishing |
| Draft | Generated content awaiting review or publishing |
| Review | The approval step: approve, request changes, or reject a draft |
| Publication | A published post on a platform, with tracked metrics and comments |
| Asset | An image owned by a tenant: uploaded, generated, or used as cover |
| Image mode | How a task gets images: `generate` or `library` |
| MCP | Model Context Protocol — plugin system for external tools |
| Access token / Refresh token | Bearer credentials from sign-in; the refresh token rotates on every use |
