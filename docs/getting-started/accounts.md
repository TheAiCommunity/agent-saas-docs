## Tenants

Every account belongs to a tenant: a customer space that holds its own members, content, connected accounts, and settings. A tenant is identified by a **tenant code**, a short code you enter at sign-in. The tenant code is not the same as the tenant ID that appears in API responses; the code is for signing in, the ID identifies the tenant internally.

You can sign in with a username, an email address, or a phone number, plus your password.

## First login

If a tenant admin created your account, the first sign-in asks you to set a new password before you can use the product. This is normal and happens once.

## Sessions

Signing in creates a session bound to your device. Sessions expire after a period of inactivity; the app refreshes its token automatically while you work.

You can sign out from the app at any time. Tenant admins can see and revoke member sessions from the management console — for example, when a device is lost.

## Password changes

Change your password from your profile settings. If you lose access to your account, contact your tenant admin.
